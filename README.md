WFH Perian is a lightly-edited version of the the Perian project's original QuickTime component which adds support for WebM and adjusts the MKV importer to work better with QuickTime X 10.2 and support more codecs.

WFH Perian does not, by itself, add support for new codecs. However, it is intended to be used alongside two other components built from https://github.com/wowfunhappy/ffusion, which _will_ add support for new codecs! (The linked respository is _also_ based on Perian; it was just easier to get newer video codecs working in a separate version of the codebase that doesn't have to simultaneously support all the older codecs.)

To install all of this, go to https://mavericksforever.com and download the "WFH Components". These are primarily tested with QuickTime Player X 10.2 on 10.8 Mountain Lion and 10.9 Mavericks, but have been reported to work with QuickTime 7 on versions of macOS as recent as 10.14 Mojave.
